# 小说记忆

给长篇小说准备的记忆层。原文按章切好留在磁盘上（L0），agent 读的时候把理解写成摘要、弧、印象、世界观、事实表和文风样本（L1–V），之后不再需要原文进上下文，也能讨论剧情、续写、回查细节。

每条记忆都带章节出处 `[ch123]`，能回原文核对——这是防幻觉的核心：记忆可以有损，但必须可回溯。

## 七层

- **L0 原文** — 按章切分，不压缩，按需读取。
- **L1 章摘要** — 一行摘要 + 事件标记（转折 / 伏笔埋设 / 伏笔回收 / 母题 / 人物入场 / 人物退场 / 关系变更 / 世界观揭示）。近 50 章常驻，更早的压成一行。伏笔只收「有具体对象、读者会追问后来呢」的东西；主题句、反复意象、作者的讽刺记成母题，单独计数，不算欠账。
- **L2 弧摘要** — 以弧为压缩单位（10~30 章），由 agent 通读后划分。每回合常驻一张全书弧表（一行一弧，长书也不会忘记自己走到哪）加最近 5 弧的详细摘要。
- **L3 全局印象** — 读者感想与作者分析分开存；读的时候另有「途中的感想」条目（单章单通道最多 3 条），读完后把总账写进 L3，条目留着对照。讨论期只往 decisions 日志追加，过若干轮再合并。
- **L4 世界观** — 索引常驻、正文按需的两级结构；A 级常驻，B 级只占一行；标签带别名表。
- **F 事实表** — 人物 / 关系 / 伏笔，永不压缩（时间点留在 L1 那一行里，不另建表）。关系两端可以是人物、组织、地点或种族。人物分 A/B/C 三档，C 级龙套死了 20 章后可归档，墓碑保留外号表和一行说明。未回收伏笔带描述常驻摘要，一直挂到收回为止。
- **V 文风** — 默认取已读的最后两章全文（可手动指定、可锁定，锁定后 AI 不得改动），另存有味道的整段摘录（总字数上限默认 2000，页面可调，超出从最旧的裁）。

- **自定义笔记** — 一页按任务分节的空白，放用户另外布置的事（比如「记下唯美摘抄」）。agent 只追加，默认不读、不进上下文；用户可在页面上整页改。字数默认不设上限，需要时在页面上勾「限制字数」并填数字。

总字数不到 15 万的小书直接全读，不进压缩管线。切章认 第X章/回/节/集/部/篇/卷、序言、楔子、尾声、后记、番外/外传/特别篇；番外一、番外·xxx 这种写法也单独成章。

读原文必须由 agent 自己一批一批读，不允许拆给子代理——拆碎的上下文接不上，前因后果会断。

## 工具

`novel_index`、`novel_find`、`novel_memo`、`novel_world`、`novel_check`。事实、世界观和文风共用一个读写入口（`novel_world`），因为它们都是客观信息。

## 页面

设置 → 插件 → 小说记忆：按书查看和修改 L1–L4、F、V 的全部内容。印象条目、人物墓碑、文风窗口和摘录都在这里改；每条都能展开看全文、直接改字——写歪了就改那一句，不用重读。最后一个页签是「自定义笔记」，像一张空白 txt，随你写，也随 agent 往里追加。
